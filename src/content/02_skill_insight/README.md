# 02_skill_insight (스킬 및 인사이트 공유 보관소)

본 폴더는 스터디 멤버들이 연구 및 빌딩 도중 획득한 고품질 기술 분석 정보, API 팁, 그리고 재사용 가능한 코드 조각(Code Snippet)을 자율 공유하는 공간입니다. (공개 대상)

## 파일 명명 컨벤션
- **구조**: 자유 제목 마크다운 파일 (`{기술명_팁제목}.md` 권장)
- **예시**: `Nextjs_Realtime_WebSocket_Tip.md`

## 작성 규칙
1. 꿀팁 공유 시 `99_templates/인사이트_주제.md` 또는 `99_templates/개념_주제.md` 템플릿을 복사하여 자유롭게 작성합니다.
2. Frontmatter 메타데이터(`title`, `author`, `tags`, `date`)를 성실히 채우면, 공개 웹사이트의 `/tools/` 라우트 상에 태그 필터와 함께 이쁘게 출력됩니다.
3. 멤버가 자율적으로 작성하여 저장하면, 에이전트 자동 푸시 파이프라인에 의해 실시간 반영됩니다.
