## 1. 이번 주 과제 요약
이번 주차에는 Astro 사이트와 Next.js 대시보드의 통합 디자인 가이드라인 수립을 목적으로, Tailwind CSS 환경에서 HSL 색상 모델을 활용한 Hues 테마를 기획하고 적용했습니다. 이를 통해 다크 모드와 라이트 모드 전환 시 일관성 있는 색 대비와 높은 가시성을 확보하고자 하였습니다.

## 2. 시도 및 실패 기록
- **시도**: 꼬리표처럼 고정된 HEX 코드를 제거하고, HSL 기반의 dynamic theme 변수들을 `globals.css` 파일에 통합 선언했습니다.
- **실패**: 일부 브라우저 및 Tailwind 컴파일 시점에서 커스텀 HSL 색상 변수를 해석하지 못해 화면이 완전한 흰색으로 표시되는 렌더링 붕괴가 있었습니다.
- **해결**: Tailwind config의 theme extend 설정을 HSL 함수 포맷(`hsl(var(--hue-base), 12%, 11%)`)에 맞게 정밀 매핑하여 테마 파싱 오류를 제거했습니다.

## 3. 핵심 인사이트
동적 테마 시스템 구축 시에는 하드코딩된 값(HEX 등)을 배제하고, CSS Variable과 런타임 HSL 연산을 함께 사용하여 유연한 다크 모드 스위칭을 유지하는 것이 유지보수에 큰 이점이 됩니다.
