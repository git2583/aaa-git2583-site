# 01_gallery (프로젝트 갤러리 보관소)

본 폴더는 스터디 시즌 동안 멤버들이 실제로 구현 및 배포를 완료한 AI 서비스 및 파이프라인 프로젝트 정보를 아카이빙하는 공간입니다. (공개 대상)

## 파일 명명 컨벤션
- **구조**: `{프로젝트명}.md` (띄어쓰기는 언더바`_`로 대체 권장)
- **예시**: `Sample_Project.md`

## 작성 규칙
1. 프로젝트 완료 시 `99_templates/갤러리_서비스명.md` 템플릿을 복사하여 작성합니다.
2. Frontmatter 메타데이터(`maker`, `link`, `thumbnail`, `description`)를 누락 없이 채워 넣어야 웹사이트 갤러리 카드 형태로 올바르게 렌더링됩니다.
3. 썸네일 이미지는 `frontend/public/assets/gallery/` 디렉토리에 저장한 후 상대/절대 경로로 매핑합니다.
