# Season 1: AI Builder Study 커리큘럼

본 문서는 AAA TEAM AI 빌더 스터디 시즌 1의 8주차 교육 과정 및 주차별 빌딩 목표를 정의한 공식 커리큘럼 파일입니다. (웹사이트 `/curriculum/`에 노출됩니다.)

---

## 스터디 개요
- **목표**: 개인 생산성 도구의 한계를 깨고 AI 에이전트를 실무 파이프라인 및 서비스에 직접 이식하는 1인 1빌딩 완료.
- **기간**: 8주 코스 (2026-05-24 ~ 2026-07-19)

---

## 주차별 로드맵 (Weekly Roadmap)

### Phase 1: 기반 다지기 및 환경 구축 (Week 1 ~ 2)
- **Week 01**: 로컬 개발 도구 셋업 및 깃허브 협업 파이프라인 이해
  - *미션*: 본인의 로컬 옵시디언 환경과 개인 레포지토리를 연동하고 첫 마크다운 문서 커밋 완료하기.
- **Week 02**: 프로덕션 배포 파이프라인 및 CI/CD 구축
  - *미션*: 간단한 Astro 정적 웹사이트를 Vercel에 배포하고 자동화 Webhook 연동하기.

### Phase 2: AI 자동화 및 데이터 파이프라인 (Week 3 ~ 5)
- **Week 03**: LLM API 연동 및 비동기 파이프라인 설계
  - *미션*: Python / Node.js를 사용해 OpenAI / Anthropic API를 연동하고 비동기 생성 스크립트 작성하기.
- **Week 04**: n8n을 이용한 시각적 워크플로우 자동화
  - *미션*: 웹훅 수신 ➡️ AI 텍스트 가공 ➡️ 노션/DB 기록으로 이어지는 n8n 시나리오 설계하기.
- **Week 05**: 벡터 데이터베이스(Vector DB) 및 RAG 시스템 구축
  - *미션*: 로컬 문서를 임베딩하여 Vector DB에 적재하고 검색 기반 응답 챗봇 API 구현하기.

### Phase 3: 서비스 구현 및 실전 검증 (Week 6 ~ 8)
- **Week 06**: 프론트엔드 UI/UX 설계 및 상태 기반 렌더링
  - *미션*: 사용자 입력에 맞춰 AI 생성 상태(Pending ➡️ Processing ➡️ Completed)를 표현하는 UI 구축하기.
- **Week 07**: 크로미움 브라우저를 통한 시각적 회귀 자가 검사(QA)
  - *미션*: 내장 브라우저 자동화 스크립트를 구현하여 사이트 레이아웃 깨짐 자동 진단 및 복구 빌드 태우기.
- **Week 08**: 최종 데모데이 및 프로젝트 릴리즈
  - *미션*: 본인이 만든 서비스를 외부에 릴리즈하고 운영 통계 데이터 취합하기.
