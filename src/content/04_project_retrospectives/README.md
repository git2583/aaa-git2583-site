# 04_project_retrospectives (프로젝트 회고록 보관소)

본 폴더는 스터디 시즌 종료 또는 중간 마일스톤 달성 시 각 멤버들이 빌드 성과와 기술적 반성을 체계적으로 기록한 포스트모템 회고록을 보관하는 공간입니다. (공개 대상)

## 파일 명명 컨벤션
- **구조**: `Season_1_{닉네임}_회고.md`
- **예시**: `Season_1_빌더A_회고.md`

## 작성 규칙
1. 프로젝트 마감 후 `99_templates/Season_1_Retrospective_Template.md` 템플릿을 복사하여 내용을 작성합니다.
2. 단순히 좋았던 점 나열을 넘어 **KPT(Keep, Problem, Try)** 형식을 철저히 준수하여 기술적 자산이 되도록 명세합니다.
3. `/publish` 명령어를 통해 웹사이트 `/retrospectives/` 라우트에 자동 정적 배포가 완료됩니다.
